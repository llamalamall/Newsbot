# Contributing to Newsbot

Thank you for your interest in contributing to Newsbot! This document provides guidelines for contributing to the project.

## How to Contribute

1. **Fork the Repository**
   - Fork the Newsbot repository to your GitHub account
   - Clone your fork locally

2. **Create a Branch**
   - Create a new branch for your feature or bug fix
   - Use descriptive branch names (e.g., `feature/add-twitter-search`, `fix/github-api-error`)

3. **Make Changes**
   - Make your changes in your feature branch
   - Follow the existing code style and conventions
   - Add comments where necessary
   - Update documentation if needed

4. **Test Your Changes**
   - Test your changes locally using `./run_local.sh`
   - Ensure no existing functionality is broken
   - Add tests if applicable

5. **Commit Your Changes**
   - Write clear, concise commit messages
   - Reference any related issues in your commit message

6. **Submit a Pull Request**
   - Push your changes to your fork
   - Open a pull request against the main repository
   - Describe your changes clearly in the PR description
   - Link any related issues

## Code Style

- Follow PEP 8 for Python code
- Use type hints where appropriate
- Add docstrings to functions and classes
- Keep functions focused and modular

## Areas for Contribution

- **New Search Sources**: Add support for additional sources (Twitter/X, Reddit, RSS feeds, etc.)
- **Improved Filtering**: Better algorithms for filtering relevant content
- **Enhanced Reports**: New report formats or visualizations
- **Performance**: Optimize search and aggregation performance
- **Documentation**: Improve documentation and examples
- **Bug Fixes**: Fix any bugs or issues you encounter

## Reporting Issues

- Use the GitHub issue tracker
- Provide detailed information about the issue
- Include steps to reproduce
- Share relevant logs or error messages

## Questions?

Feel free to open an issue for any questions or discussions about contributing.

Thank you for helping make Newsbot better!
